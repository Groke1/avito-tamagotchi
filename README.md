# avito-gamification-hackathon

## Скрипты

Запустить генерацию кода:
```bash
make generate
```

Запуск тестов:
```bash
make test
```

Запустить сервер:
```bash
make run
```

Остановить сервер:
```bash
make stop
```

Запуск линтера:
```bash
make lint
```

Запуск линтера для конкретного сервиса:
```bash
make lint-<name>
```
